Netflix India Clone 🎬

A responsive Netflix India landing page clone built with HTML, CSS, and JavaScript, designed to recreate the layout, visual structure, and interactive elements of the Netflix homepage.

✨ Features

- Responsive Netflix-inspired landing page
- Hero section with background image and overlay
- Navigation bar with language selector and Sign In button
- Email input with floating label interaction
- Responsive TV, mobile, and device showcase sections
- Background video integration
- Download animation section
- Interactive FAQ accordion
- Responsive layout for mobile, tablet, and desktop screens

🛠️ Tech Stack

- HTML5 – Page structure
- CSS3 – Styling, Flexbox, positioning, and responsive design
- JavaScript – DOM manipulation and FAQ interactions
- Font Awesome – UI icons
- Google Fonts – Poppins typography

⚙️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

No additional installation or dependencies are required.
